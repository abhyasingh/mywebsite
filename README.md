# Premium Developer Portfolio

A responsive, minimal portfolio template built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page structure and editable portfolio content
- `style.css` — colors, layout, responsive styles
- `script.js` — mobile navigation and current footer year

## Personalize before publishing
1. In `index.html`, replace **Alex Morgan** with your name.
2. Replace `hello@example.com` with your real email address.
3. Update the About text, skills, project names, descriptions, and links to reflect your real work.
4. The project previews are decorative mockups; replace them or link each project card to a live demo/GitHub repository.
5. Open `index.html` in your browser to preview the site.

## Publish on InfinityFree
1. Upload `index.html`, `style.css`, and `script.js` to your hosting account's `htdocs` folder.
2. Make sure `index.html` is directly inside `htdocs`, not inside an extra nested folder.
3. Open your domain and refresh the page. If the old version remains, hard-refresh with `Ctrl + F5`.

The Google Fonts import requires an internet connection. The site itself uses no build tools or frameworks.
